# Project: Expense Tracker 🌟
A simple and user-friendly Expense Tracker built using HTML, CSS, and JavaScript to help users record, manage, and track their daily income and expenses.

🛠️Technologies Used:
HTML – Structure of the application
CSS – Styling and responsive design
JavaScript – Functionality and transaction management

📂 Project Structure:
## EXPENSETRACKER/
- index.html
- style.css
- script.js


  ⚙️ How to Run:
Clone the repository: git clone https://github.com/purnima-gangwar/Expense_Tracker.git
- Open the project folder.
- Open index.html in your browser.

## Features:
- Add income
- Add expense
- Delete transaction
